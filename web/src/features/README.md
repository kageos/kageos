## Features

`features/*` 承载独立后台业务域页面与其私有组件。

- `features/agent`: LLM 与工作台后台管理域。
- `features/auth`: 登录、注册、找回密码与测试用户入口。
- `features/organization`: 组织架构与用户管理域。
- `features/permission`: 权限申请与角色管理域。
- `features/user`: 用户个人设置与用户域私有组件。
- `architecture/*`: workspace 主链路与其专属运行时。
- `shared/*`: 跨域复用组件、类型与编辑器扩展。
