# 系统资源监控

`system` 超管可以在“系统设置 -> 运行状态”查看 kageos 所在服务器的运行负载和存储容量。

## 展示内容

- CPU 核心数、CPU 使用率，以及操作系统支持时的最近 1、5、15 分钟平均负载；
- 内存、Swap、网络收发速率及累计流量、磁盘读写速率；
- kageos 持久化存储所在文件系统的总量、已用量、可用量和使用率；
- 自动识别宿主机存储和 Docker / Podman 虚拟机存储，并按存储池展示容量；
- MySQL、MinIO、工作空间、运行数据、日志、容器镜像与存储层的占用，以及同一存储池中未归类的其他数据；
- 用户、工作空间、服务目录、函数、应用数据库和定时任务数量；
- 平台数据库与应用数据库的数据和索引逻辑大小；
- 24 小时、7 天、30 天的 CPU、磁盘、内存和网络走势；
- 到磁盘使用率 85% 扩容线的预计天数。

## 分层采集与保留

采集分成互不阻塞的三类任务：

- 实时运行指标每 30 秒读取一次，仅访问操作系统计数器；每 10 分钟把平均 CPU、最高 CPU、网络和磁盘 IO 平均速率及最后状态写入 `system_resource_samples`；
- 平台规模每小时由 HR、工作空间、应用运行时和定时任务服务分别执行只读聚合，再通过内部 NATS 汇总，写入 `system_platform_snapshots`；
- 容量盘点在服务启动后执行一次，之后每天按服务器本地时区 02:30 执行，写入 `system_capacity_snapshots`。目录递归、Docker / Podman 统计和数据库逻辑大小只在该任务中执行。

三张历史表只保留 30 天。每日容量任务使用硬删除清理 `collected_at` 早于保留线的数据，避免软删除数据继续占用表空间。页面展示每类任务的上次成功时间、耗时、状态和下次采集时间。

启动时若工作空间、应用运行时或定时任务服务尚未就绪，平台规模会每分钟重试；应用数据库容量来源会在 5 分钟后补采一次。来源不可用会显示为“部分成功”，不会用零值冒充真实数据。

运行状态页面每 30 秒只刷新当前快照；历史曲线首次进入时加载，之后每 10 分钟或切换时间窗口时更新，避免查看 30 天窗口时重复传输整段历史。

任一可获取容量的存储池使用率达到 80% 时提示准备扩容，达到 90% 时提示立即扩容；告警会标明具体存储池。主存储积累至少 24 小时历史后，即使当前使用率较低，按近期增长速度预计 30 天内达到 85% 时也会提前预警。

## 环境与存储自动发现

采集器不要求管理员为不同部署方式分别配置。启动后会自动识别：

- 源码开发环境：统计仓库中的 `namespace`、`data` 和 `logs`，并探测开发配置指定的 Docker 或 Podman；
- AIO：优先使用 `KAGEOS_AIO_DATA_DIR`，否则发现 `/var/lib/kageos`；
- 容器化生产：识别容器标记和 `/app` 工作目录；
- 宿主机生产：读取 `.kageos/prod/kage.yaml` 中的 `storage.root`；
- 其他布局：回退到 kageos 根目录或当前系统文件系统根目录。

CPU、内存、Swap、网络、磁盘容量、磁盘 IO 和运行时间使用跨平台系统接口采集，支持 Linux、macOS 和 Windows。Windows 不提供 Unix Load Average 时，页面自动使用 CPU 使用率，不把“不适用”误报成故障。Windows 数据目录使用盘符和原生路径；Docker Desktop / Podman Machine 仍按独立存储池处理。

在 macOS / Windows 的 Docker Desktop 或 Podman Machine 场景中，容器数据位于独立虚拟磁盘。采集器会把宿主机与容器引擎显示为两个存储池，避免把 MySQL、MinIO 占用误算到宿主机磁盘。若容器引擎只提供分类占用、不提供虚拟磁盘总容量，页面会显示已知占用并明确标记“总容量未知”。

`KAGEOS_MONITOR_STORAGE_ROOT` 仅作为非标准部署布局的显式覆盖，不是正常部署的必填项。该目录必须与真实持久化数据位于同一文件系统，才能正确反映扩容所关心的磁盘容量。

目录占用统计只读取当前 `hr-server` 进程可见的本地目录。使用外部 MySQL、外部对象存储，或没有把对应目录挂载给主容器时，页面会显示“未挂载或使用外部服务”，不会把远端容量误算成本机容量。

数据库逻辑容量来自 `information_schema.tables` 的数据与索引汇总，并限制为当前平台数据库和 `app_databases` 已登记的应用数据库，页面最多展示前 10 个。数据库账号没有统计权限时显示“不可用”，不会把未知容量当作零。

## 权限

资源接口和“运行状态”页面只允许平台内置的 `system` 超管访问。普通管理员、组织管理员和普通用户不会获得服务器容量、目录结构或运行负载信息。
