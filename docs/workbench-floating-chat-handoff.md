# 工作台底部浮动对话交接文档

## 目标

在工作台底部提供一个低干扰、半透明、可手动折叠的对话输入框，让用户不需要打开右侧对话栏，也能直接输入需求并回车执行。任务可以在后台持续运行，SSE 连接不能因为用户切换目录或会话而中断。

当前单机 mock：

- 页面：`docs/workbench-floating-chat-mock.html`
- 配色记录：`docs/workbench-floating-chat-color-system.md`
- 本地预览：`http://127.0.0.1:53719/workbench-floating-chat-mock.html`

## 当前定稿

底部区域保留三层：

1. 当前会话输出条：显示正在查看的 SSE 输出，右侧显示产物。
2. 会话摘要条：显示当前目录下少量关键会话，点击只切换当前输出。
3. 输入框：支持继续输入、回车发送、任务运行中排队发送。

主界面不要出现复杂控制项。复杂操作统一收进“会话中心”弹窗。

## 必须保留的交互

- 整个底部浮动输入框只支持手动折叠和展开。
- 不允许 hover 自动展开。
- 不允许 hover 摘要条时浮出额外摘要卡片。
- 点击会话摘要只切换当前 SSE 输出，不弹窗。
- 当前查看的会话摘要上方需要有箭头指示。
- 点击“会话中心”才打开弹窗。
- 顶部右侧不要再放重复的后台会话入口。
- 底部主界面不要放“运行中 / 等待交互 / 完成”等调试或复杂按钮。

## 会话中心

会话中心负责承载复杂内容：

- 当前目录会话。
- 全部会话。
- 搜索目录、函数、需求。
- 按全部、执行中、待确认、有产出、已完成过滤。
- 历史会话和跨目录会话管理。
- mock 场景控制也放在这里，不暴露在主界面。

点击会话中心里的会话：

- 如果是当前目录摘要中已有会话，切换到底部对应摘要和 SSE 输出。
- 如果是其他目录会话，后续真实实现应切换到对应目录并恢复该会话输出。
- 不应打开旧的聊天详情弹窗。

## SSE 和后台执行

核心原则：

- 会话运行时保持 SSE 连接，不因 UI 折叠、目录切换、页面内视图切换而断开。
- 用户从 A 会话切到 B 会话时，A 继续后台执行。
- 再切回 A 时，应立即看到最新流式输出。
- 折叠状态下新输出只做徽章或高亮提示，不自动展开。
- 会话数量增长后，底部只展示少量关键摘要，完整列表放到会话中心。

建议数据模型至少包含：

- 会话 id。
- 所属目录 id / path。
- 函数或工具名称。
- 用户需求摘要。
- 状态：执行中、待确认、有产出、已完成、失败。
- 未读输出数量。
- SSE 连接状态。
- 最新日志片段。
- 产物列表。
- 排队输入草稿。

## 输入框

输入框需要支持：

- 直接输入文字。
- 回车发送。
- Shift + Enter 换行。
- 任务执行中继续输入，发送后进入排队。
- 折叠后保留草稿。
- 当前目录 pill。
- 模型选择。
- 定时执行入口。
- 附件按钮。

特别注意：输入框必须支持拖拽上传文件。

拖拽上传要求：

- 用户把文件拖到输入框或输入区时，出现明确的 drop 状态。
- drop 后显示文件 chip，包括文件名、大小、上传状态、删除按钮。
- 支持多个文件。
- 支持上传中、上传成功、上传失败、可重试状态。
- 发送消息时，文本和附件一起进入会话请求。
- 如果任务正在执行，带附件的消息也应进入排队。
- 拖拽上传不能影响 SSE 输出持续接收。
- 文件上传进度和错误提示不要遮挡主工作区。

## 右侧产物区

当前输出条右侧展示当前会话产物：

- 收起状态下展示首个产物和数量提示，例如 `图片 3项`。
- 最大化状态下展示完整产物列表和标题，例如 `当前产物 3项`。
- 产物需要跟随摘要切换同步变化。
- 有产出状态应用蓝色提示。
- 执行中产物可以显示“渲染中”“读取中”等轻量状态。

## 最大化输出

当前输出条需要支持最大化：

- 最大化后输出区域明显变大。
- 左侧显示完整日志流。
- 右侧显示完整产物列表。
- 底部摘要条和输入框仍可见，方便继续输入。
- 不显示其他复杂控制项。

## 视觉和配色

后续主站参考当前 mock 的配色，不要重新大改方向。

关键基调：

- 深色背景。
- 半透明蓝黑面板。
- 高亮蓝 `#37a3ff`。
- 紫色 `#776bff`。
- 绿色执行态 `#2bd59f`。
- 黄色待确认 `#f6bd4d`。
- 红色徽章 `#ff6d7e`。

完整色板见：`docs/workbench-floating-chat-color-system.md`。

## 不要做

- 不要恢复顶部右侧后台入口。
- 不要让 hover 打开工作台、弹窗或摘要浮层。
- 不要把复杂状态控制塞到底部主界面。
- 不要点击摘要就打开详情弹窗。
- 不要因为折叠 UI 而断开 SSE。
- 不要让底部组件大面积遮挡工作台内容。

## 下一步实现建议

1. 先把 mock 中的布局和交互拆成真实组件。
2. 接入会话状态 store，支持多会话并行。
3. 接入 SSE 管理层，确保后台持续流式接收。
4. 实现摘要切换和会话中心列表联动。
5. 实现输入框排队发送。
6. 实现拖拽上传文件和附件 chip。
7. 接入产物列表和未读徽章。
8. 最后再接入真实目录切换和跨目录会话恢复。
