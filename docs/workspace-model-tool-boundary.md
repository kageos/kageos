# 工作台模型工具边界

工作台模型使用业务资源及公开 SDK。平台构建目录、容器、依赖准备、内部追踪与部署实现不属于模型的操作接口。

## 当前约定

- `build_workspace` 成功只返回工作空间、版本、后续测试阶段及概括后的告警；不返回构建 trace、物理路径、内部 commit。完整 trace 继续保留在平台原有诊断链路。
- 构建失败的原始异常只写平台日志。可识别的当前应用业务源码错误转换为工作台文件路径，保留行号和编译错误；SDK schema 错误保留相关业务诊断。
- 无法识别为业务代码诊断的构建失败返回 `agent_platform_build_failure` / `platform_build_failed`，不产生自动修代码的交接。此分类是保守回退，不代表已经确定了基础设施根因。
- 业务 `run_*` 工具只依赖资源查询提供的功能路径、字段和操作能力，不引导模型读取 Go 文件、推导路由或研究回调实现。
- `search` 后端失败返回错误 `resource_query_failed`，不能转换成“未匹配到资源”。组合查询任一后端失败时整体失败，避免把不完整结果当作完整结果。

这些约定针对新生成的工具结果，不清除已存在会话历史中的旧结果。开发角色仍可读取其业务源码和 SDK 文档。本次不改变角色体系、业务调用参数格式或文档编辑能力。

## 验证

`core/agent-server/service/workspace_blackbox_test.go` 覆盖成功返回和输出 schema 不暴露构建细节、源码诊断路径转换、平台错误不触发代码修复、搜索失败与正常空结果区分、业务工具描述只依赖公开契约。

## Python、日志与后端异常

- Python 工具说明只描述入口函数、输入附件、输出文件、可用库和参数；不描述私有路由、镜像、容器或平台改造方式。返回值只提取 status、output、json_result、output_files，平台额外字段不透传。失败状态同步标记工具失败。
- 应用日志不返回日志文件位置；诊断文本移除已知传输/SQL/运行栈信息、遮蔽物理路径，保留业务错误及脚本行号。这是诊断展示过滤，不是任意文本的安全脱敏保证。
- 业务运行、文件/目录/文档读取与写入、任务服务和网页查询的后端调用失败使用共享错误出口。原始错误记平台日志，模型收到服务失败、超时、中断或可明确识别的权限错误。超时和服务异常不声称写入一定未发生，也不建议盲目重试。
- 本地字段、枚举、参数校验仍返回具体问题。当前后端错误多为未分类字符串，无法可靠区分的业务后端异常保守返回服务错误；后续应由服务端提供稳定业务错误类型，而不是从错误文本猜测分类。
- 此轮未改角色交接协议、定时任务成功结果结构和业务调用参数格式。

## 业务拒绝与批量写入补充

- API 非零业务响应使用 `apicall.BusinessError` 保留错误类别、编号和原因，兼容原有 Error() 文本；主仓和 SDK 同步契约。工具层保留业务拒绝原因，对旧接口夹带的已知 SQL/运行时异常仍按服务故障展示。旧业务消息的识别过滤不是任意异常文本的完全脱敏保证。
- 写入前校验枚举所有提交字段，拒绝不在本次操作可写字段集合里的字段。隐藏于新增/编辑场景的字段和 ID 不接受 Table 写入；没有 schema 时不跳过校验。此处是 Agent 工具入口校验，不替代业务服务端鉴权或字段约束。
- Table 新增/更新批量结果具有 success、partial_success、failed 三种状态。只要有失败项，工具标记失败，同时保留成功数量、失败数量及逐条结果，避免把部分完成当全部成功或重复整批写入。
- 路由手册先区分业务操作与获授权的开发/修复，业务拒绝不触发维护或构建修复路由。
