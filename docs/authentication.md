# 登录方式配置

kageos 的第三方登录方式由管理员在“系统设置 → 登录设置”中配置。配置保存在平台数据库中，不依赖容器环境变量，也不需要重启服务。只有字段完整且已启用的登录方式才会出现在登录页。

## kageos 统一认证登录

适用于通过组织统一维护的 kageos Auth 服务复用微信公众号扫码身份。应用本身不保存公众号 AppSecret，也不直接接收微信消息回调。

在登录设置中填写：

- `Client ID`：由 kageos Auth 管理方分配的应用标识。
- `Client Secret`：由 kageos Auth 管理方生成的应用密钥。
- `回调地址`：当前 kageos 实例的精确回调地址，并由 kageos Auth 加入该 Client 的白名单。

当前官方认证服务使用 `https://auth.kageos.com`。授权过程使用 OAuth 2.0 Authorization Code，并强制启用 PKCE S256。Client Secret 只保存在平台数据库的加密配置中，不会发送到浏览器。

每个 kageos 客户端发起登录时都会携带 `prompt=login`。统一认证服务不会把某个站点已经存在的登录会话静默复用于另一个站点；用户在 App、Demo 等独立客户端建立各自会话时，需要分别完成一次微信公众号扫码。

保存并启用后，登录页显示“kageos 微信扫码登录”。首次登录仍会进入 kageos 的外部账号注册确认页，让用户选择该实例内唯一的用户 code；后续登录使用统一认证服务返回的稳定匿名身份标识。

## 微信公众号扫码登录

适用于使用已认证微信公众号的带参二维码作为登录入口。

在登录设置中填写：

- `AppID`：公众号 AppID。
- `AppSecret`：公众号 AppSecret。
- `消息 Token`：自行设置，并与公众号后台服务器配置中的 Token 完全一致。

将设置页显示的回调地址复制到微信公众号后台的服务器地址，然后选择明文消息模式。当前实现尚不支持兼容模式或安全模式的 AES 消息解密。

保存并启用后，登录页显示“微信公众号扫码登录”。浏览器生成五分钟有效的临时带参二维码：未关注用户关注公众号会触发 `subscribe`，已关注用户扫码会触发 `SCAN`。扫码状态只能消费一次。

微信不提供已验证邮箱。首次登录会进入 kageos 的外部账号注册确认页，让用户确认用户 code 和显示名称；后续使用公众号 AppID 与 OpenID 识别同一身份。

## 微信开放平台登录

适用于微信开放平台中的网站应用授权登录。

在登录设置中填写：

- `AppID`：网站应用 AppID。
- `AppSecret`：网站应用 AppSecret。
- `回调地址`：点击“使用当前回调地址”自动填入，并确保其授权回调域已配置到微信开放平台。

保存并启用后，登录页显示“微信开放平台登录”，并通过 `snsapi_login` 完成授权。优先使用 UnionID 标识用户；没有 UnionID 时使用 AppID 与 OpenID 的组合作为稳定身份。

## 安全边界

- AppSecret 和消息 Token 在设置接口中只返回“已设置”，不回传明文。
- 授权 state、扫码 attempt token 和二维码 scene 都是短时、一次性的随机值；扫码 token 和 scene 仅以 SHA-256 摘要落库。
- kageos 统一认证使用 PKCE S256；授权码、访问令牌和公众号 OpenID 不会暴露给应用前端。
- 微信身份不会因为昵称、头像或未验证邮箱而自动合并到其他账号。
- Connector OAuth 用于连接外部数据，不作为用户登录提供商。
