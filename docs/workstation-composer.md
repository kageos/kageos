# 工作台输入与资源选择

工作台聊天输入区固定为四行，长内容在输入区内部滚动。Shift+Enter 换行时保持光标可见；异步引用信息加载不会在输入期间重建编辑内容。数字员工任务编辑仍使用较大的多行编辑区。

输入 `/` 即打开资源选择器，同时搜索当前目录和其他目录中的可访问资源。当前上下文是具体资源时，使用其所属目录。没有目录上下文时搜索所有可访问目录。

- 分组：上方为当前目录及子目录，下方为其他目录；两组分别滚动，不需要切换范围。
- 类型：全部、文档、目录、数据表、表单、图表、其他。
- 搜索：继续在 `/` 后输入名称；切换类型保留关键词。
- 条目显示完整路径，便于区分同名资源。当前目录与全局搜索各批最多加载 100 条，合并去重，后续可加载更多；空筛选结果且仍有下一批时提供提示。
- 上下键选择，Enter 或 Tab 插入，Esc 关闭。每次重新打开 `/` 恢复全部类型。

资源搜索复用服务端权限检查与目录前缀过滤。数据表、表单、图表 使用函数搜索的模板类型过滤。资源菜单通过全局浮层层级显示在工作台和数字员工编辑弹层之上。

输入 `@` 默认展示当前登录用户，并标记“我自己”；继续输入姓名可搜索其他用户。资源候选显示用途摘要，插入后的引用可点击查看独立信息卡。信息卡展示名称、类型、用途和完整路径，点击时刷新资源详情；未填写说明或加载失败时显示明确提示。

从目录树拖入资源时，引用追加到已有文本末尾，并优先采用拖拽数据中的名称。没有携带名称时，通过详情查询补齐；异步名称更新只修改引用标签，不重建整个编辑器。
