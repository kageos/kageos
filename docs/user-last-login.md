# 用户管理：最近登录时间

系统用户管理列表展示最近一次成功登录的时间，按浏览器本地时区显示。
密码登录及微信、OAuth 等第三方登录共用会话创建入口：会话创建与
`user.last_login_at` 更新在同一数据库事务内完成。登录失败、账号停用、
自动刷新令牌和日常 API 请求不会更新此时间；退出登录不会清空它。

HR 服务启动时通过现有 AutoMigrate 添加可空的 `last_login_at` 字段。
用户信息响应以 RFC3339 字符串返回该字段，无记录时返回 null。
历史用户不做推测性回填，列表显示“暂无登录记录”；因此空值并不证明
该用户从未登录。部署后用户下一次成功登录时开始记录。

本字段表示成功建立登录会话的时间，不表示当前在线状态。
