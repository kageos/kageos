# Security Questionnaire / RFP Filler

这是一个商业化模板 demo：面向 B2B SaaS、外包公司、AI agency 和售前团队，把公司资料、产品文档、历史问卷答案和客户新问卷合并，生成回答草稿、引用来源、置信度和复核清单。

## MVP 范围

- 粘贴或上传公司资料、产品文档、隐私政策、历史问卷答案。
- 粘贴或上传客户安全问卷/RFP 问题。
- 自动拆问题。
- 根据资料片段匹配最相关依据。
- 生成回答草稿、置信度、状态和引用来源。
- 导出 Markdown 报告。
- 保存历史运行记录。

## 暂不做

- 不直接解析复杂 `.docx/.xlsx/.pdf` 结构，第一版建议先转成文本或 CSV。
- 不承诺答案合规准确，必须由安全、法务或产品负责人复核。
- 不接定时任务。
- 不依赖 LLM，后续可以把 `draftAnswer` 替换成模型生成。

## 路由

- `POST /rfpfiller/rfp_fill.form`
- `GET /rfpfiller/rfp_fill_history.table`
