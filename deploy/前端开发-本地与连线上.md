# 前端开发：本地启动说明

面向**只开发前端、需要后端能调通**的同学（例如 Mac 本地）。两种方式二选一即可。

---

## 方式一：直接连线上后端（推荐，零后端依赖）

不跑任何后端和 Docker，只起前端，API 全部走你提供的**线上环境**。

### 1. 克隆并安装

```bash
git clone <仓库地址>
cd ai-agent-os/web
npm install
```

### 2. 配置「连线上」

在 `web` 目录下新建 **`.env.development.local`**（可复制 `web/.env.development.local.example` 再改）：

```bash
cd web
cp .env.development.local.example .env.development.local
```

编辑 `.env.development.local`，填**线上主站地址**（能转发到 app-server、hub、storage 等的入口，不要带末尾斜杠）。例如当前线上：

```env
# 主站 + API 统一入口（Web 8999，API 也通过该端口转发）
VITE_PROXY_TARGET=http://125.122.96.207:8999
```

若你使用其他域名或 IP，把上面改成对应地址即可。

若有 WebSocket（实时能力），可再加：

```env
VITE_WS_URL=wss://你的线上域名/ws
```

### 3. 启动前端

```bash
npm run dev
```

浏览器打开控制台给的地址（一般是 http://localhost:5173）。所有接口会通过 Vite 代理打到 `VITE_PROXY_TARGET`，无需 CORS、无需本地起后端。

---

## 方式二：本地起后端（适合要改后端或没线上环境）

需要本机有 **Docker、Go、Node**。

### 1. 起基础设施（MySQL / NATS / MinIO）

在项目根目录执行：

```bash
docker compose -f docker-compose.dev.yml up -d
```

等 MySQL 就绪后（约 30 秒），可顺带建库（首次或库被清空时）：

```bash
docker exec -i ai-agent-os-dev-mysql mysql -uroot -proot -e "
SET NAMES utf8mb4;
CREATE DATABASE IF NOT EXISTS \`hub\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE IF NOT EXISTS \`app_db\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE IF NOT EXISTS \`agent-server\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE IF NOT EXISTS \`hr-server\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE IF NOT EXISTS \`app-storage\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
"
```

### 2. 起后端（网关 + 各服务）

在项目根目录按你们现有方式启动「网关 + core-server + hub-server」等（例如用 `deploy/server-deploy.sh` 的 restart 逻辑，或直接 `go run ./core/cmd/main` 等）。确保网关监听 **9090**。

### 3. 起前端（不设 VITE_PROXY_TARGET）

不要创建 `.env.development.local`，或其中**不设置** `VITE_PROXY_TARGET`，这样代理默认指向 `http://localhost:9090`：

```bash
cd web
npm install
npm run dev
```

---

## Hub 前端（应用市场）单独跑 + 连线上

若要本地只跑 **Hub 前端**（`enterprise_impl/hub/frontend`），并连线上 Hub 与主站：

```bash
cd enterprise_impl/hub/frontend
cp .env.development.local.example .env.development.local
```

编辑 `.env.development.local`：

```env
# 线上 Hub 入口（8998）
VITE_PROXY_TARGET=http://125.122.96.207:8998
# 主站入口（/hr 等走主站，8999）
VITE_OS_PROXY_TARGET=http://125.122.96.207:8999
```

然后：

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5174）。  
不配上述变量时，代理默认指向本地网关 9090 和主站 dev 5173。

---

## 小结

| 场景           | 做法 |
|----------------|------|
| 只开发前端，有线上环境 | 用 **方式一**：配 `VITE_PROXY_TARGET` → `npm run dev` |
| 要改后端或没有线上   | 用 **方式二**：Docker 起基础设施 + 本地起后端 → `npm run dev`（不配 VITE_PROXY_TARGET） |

**Hub 前端**：在 `enterprise_impl/hub/frontend` 下 `cp .env.development.local.example .env.development.local`，配 `VITE_PROXY_TARGET=线上Hub地址`、`VITE_OS_PROXY_TARGET=线上主站地址`，再 `npm run dev`（见上文「Hub 前端」小节）。
