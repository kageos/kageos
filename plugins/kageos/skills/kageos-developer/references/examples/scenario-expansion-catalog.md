# 场景扩展目录

这些不是固定模板，而是帮助模型打开视野的方案方向。实现时仍要回到用户给定工作台目录和 SDK 规则。

## 资源预约类

适合对象：会议室、车辆、设备、工位、实验室、摄影棚。

典型能力：资源台账、预约记录、空闲查询、冲突校验、使用提醒、使用率日报、紧张资源预警。

关键思路：资源状态常常来自时间占用关系，不要只看资源本身状态。

## 运维巡检类

适合对象：证书、域名、服务器、备份任务、API Token、云资源账单。

典型能力：配置台账、目标资产、执行记录、巡检表单、默认调度、失败通知、风险日报。

关键思路：长流程必须有执行记录和状态机；自动化要幂等，失败可追踪。

## 经营库存类

适合对象：商品、供应商、采购、销售、库存、收银记录。

典型能力：商品台账、入库表单、出库表单、库存流水、销售趋势、库存预警、每日经营简报。

关键思路：库存和资金变化必须事务化；流水事实记录默认只读。

## 客服工单类

适合对象：客户问题、内部工单、设备报修、IT 支持、售后请求。

典型能力：工单台账、状态流转、负责人、优先级、SLA 到期提醒、超时日报、处理质量分析。

关键思路：简单状态更新优先用 Table 更新回调；超时提醒用调度或定时会话。

## 人事招聘类

适合对象：岗位、候选人、面试、Offer、入职资料。

典型能力：岗位台账、候选人库、面试安排、评价表单、阶段漏斗、面试提醒、招聘周报。

关键思路：阶段漏斗和提醒比 CRUD 更有业务价值。

## 内容情报类

适合对象：公众号文章、行业新闻、竞品动态、投融资信息、政策公告。

典型能力：关键词配置、定时采集会话、深度阅读、摘要报告、来源归档、每日推送。

关键思路：这类更适合无人值守定时会话，而不是写死成单一 Form。

## 文件处理类

适合对象：Excel、CSV、PDF、图片、视频、合同、发票。

典型能力：上传解析、批量转换、结构化抽取、结果文件下载、处理历史、失败原因记录。

关键思路：一次性处理用 Form；处理历史用只读 Table；结果文件走文件响应，不要返回大字段。
