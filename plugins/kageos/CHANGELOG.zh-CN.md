# 更新日志

## 0.3.1 — 2026-08-16

- 新增场景包、目录和目录内资源三层边界：场景包负责组合发现，目录对应独立数据库和 HTTP 边界。
- 目录设计前强制判断核心业务对象、独立闭环、共享数据需求和拆分/合并理由。
- 跨目录 HTTP 默认只作为可选增强；补充数据所有者、幂等、失败可见、重试、鉴权和禁止跨库事务等门禁。
- 插件统一入口新增场景包规划路由和默认提示词，确保后续新目录设计主动应用这套原则。

## 0.3.0 — 2026-08-15

- 新增 `kageos-contributor`，主打从普通本地电脑到成功打开 kageos：环境检查、源码拉取、Podman/Docker 选择、`kagectl` 启动、前端启动、健康验证和登录交付。
- 增加 Podman machine 数据安全门禁；已有 machine 或疑似有数据时禁止直接初始化、删除或重置。
- 启动成功后可继续源码导览、问题复现、聚焦修改、验证矩阵和 PR 准备。
- 统一入口 `kageos` 现在能区分平台源码贡献与工作空间目录开发，并路由到对应专业 Skill。

## 0.2.0 — 2026-08-15

- 新增统一入口 `kageos`，编排目录设计、本地构建、平台构建、真实验收、目录包导出、发布准备、Hub 投稿和状态确认。
- 新增 `kageos.delivery-run.v1` 交付记录，支持阶段门禁、制品 SHA-256、过期证据失效和失败续跑。
- 将插件元数据、默认提示词、安装文档和主要工作流改为中文优先。
- 同时提供 Codex 和 Claude Code 插件清单。
- 新增确定性发布包、校验文件、本地留档、官网静态下载和可选对象存储上传流程。
