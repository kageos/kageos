操作步骤

先做预检，确认环境和依赖；需要恢复时先开维护模式，再执行恢复。页面当前按所选资源类型执行动作。

维护模式

恢复前建议先开启。开启后主站会自动切到 503 维护页，避免外部继续写入。

创建快照

当前会按右侧选中的资源类型创建快照。只有 namespace 需要额外输入相对路径。

批量清理 pre-restore

清理当前资源下旧的自动快照，只保留最近 N 条。手工快照不会动，适合日常收口历史恢复点。

当前只清理所选资源类型下的 pre-restore 快照，不会删除手工快照。

恢复当前选中快照

先在右侧列表选中一个快照。
恢复前会自动创建一份 pre-restore 快照。当前版本仍建议你先确认维护模式已开启。
