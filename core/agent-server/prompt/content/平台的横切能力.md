关于权限
包括我们的权限系统也一样实现了通过full-code-path 来管理我们的权限懂吗？我们在写代码的时候不需要关心任何权限问题

关于流程审批
假如我们有个证书管理的系统，我们希望新增证书需要审批
/luobei/odv/cert/cert_list.table

我们的平台（中台）的逻辑是允许在页面配置（table）提交/更新/删除的审批策略
包括form的提交也是支持审批的

例如用户提交的是

证书名称：*.cert.ai-agent-os.com
使用期限：1年
负责人：liubeiluo


用户提交数据到中台，然后我们中台存在一个通用的流程系统，可以让审批人看到用户的提交数据，对数据进行审批，然后决是否通过，如果通过的话，数据才会执行我们的代码（回调），审批没通过数据一直在中台，对我们完全无感知
无论是form的提交还是table的新增，修改，删除都是这个逻辑，我们中台的流程引擎完全具备这个审批能力，支持各种复杂的条件审批，串签，并签，会签，条件签，等等，这个只需要在页面配置即可是通用能力，无需在代码中关心，只需要明白，只要到了触发回调的那一步，说明整个审批已经完全通过了
