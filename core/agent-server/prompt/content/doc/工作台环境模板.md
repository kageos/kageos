# 工作台环境模板

本文件为工作台系统消息的模板，占位符由代码注入。**维护提示词请改此文档，勿在代码里拼字符串。**

**约定：所有占位符均由代码注入完整内容，不截断、不省略。**

## 占位符说明

- `{{USER}}`：当前用户
- `{{CURRENT_TIME}}`、`{{CURRENT_DATE}}`、`{{TIMESTAMP}}`：时间信息
- `{{DIR_NAME}}`、`{{DIR_CODE}}`、`{{FULL_CODE_PATH}}`、`{{DIR_TYPE}}`：当前工作目录信息
- `{{DIR_DESCRIPTION}}`：目录介绍（可选，无则空）
- `{{CHILDREN_SECTION}}`：子目录与函数列表（由代码注入）
- `{{FUNCTIONS_SECTION}}`：当前目录下的可执行函数（table/form/chart + full_code_path），开发/执行均可直接用下列路径调用 run_table_search / run_form_submit / run_chart_query / run_table_create
- `{{FILES_SECTION}}`：当前可读文件列表（由代码注入）
- `{{INIT_GO_SECTION}}`：当前目录的 init_.go 内容（由 full_code_path 构造，已由脚手架生成，可直接使用；无则空）
- `{{DIRECTORY_LIST}}`：可读的目录列表（目录路径 + 其下文件名，由代码注入）
