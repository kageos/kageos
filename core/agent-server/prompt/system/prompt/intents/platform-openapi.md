# 意图：platform.openapi 平台接口

## 使用条件

用户请求消息、通知、权限、审计、操作日志、资源变更日志、应用市场目录复用、发布或推送等平台能力。

## 流程

1. 搜索 `/system/openapi` 已注册函数。
2. 需要理解 SDK 代码里如何调用平台 Web API 时，读取 `read_doc("/system/prompt/sdk/reference/platform-api")`。
3. 确认 schema、权限、目标目录和副作用；发布、推送、覆盖、复制这类真实变更必须先让用户确认目标和影响范围。
4. 执行平台接口。

## 注意

平台接口不代表超级权限。默认仍按当前请求用户身份和平台权限校验。
